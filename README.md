\# Pratik Singh — Personal Portfolio



A modern personal portfolio website built with HTML, CSS, JavaScript, Node.js and Express.



\## Features



\- Modern responsive design

\- Home page

\- About page

\- Skills page

\- Projects page

\- Contact page

\- Resume page

\- Contact form

\- Node.js backend

\- Express API

\- Gmail email integration
